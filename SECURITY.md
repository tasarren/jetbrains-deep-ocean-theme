# Security policy

## Supported versions

Security fixes target the latest Deep Ocean Dark release. Until the first release, report issues against `next`. Do not assume older One Dark plugin versions are maintained here.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tasarren/jetbrains-one-dark-theme/security/advisories/new). Do not disclose credentials or exploitable details in public issues. If private reporting is unavailable, open an issue requesting a private contact without including sensitive details.

If a credential is exposed, revoke or rotate it immediately; deleting a file or rewriting Git history does not invalidate a leaked token.
